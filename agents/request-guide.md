# Sending a request

Send whatever you already have. A PRD, a one-pager, a Figma file, a Slack thread, a screenshot, or a
single sentence — all of it works. There is no template to fill in and no form.

## What good context covers

However it arrives, these are the things worth knowing. Most product specs already carry them; a
quick prompt usually carries one or two, which is fine.

| | |
|---|---|
| **The problem** | What is wrong today, and for whom |
| **The opportunity** | Why it is worth solving now |
| **What success looks like** | How you would know the design worked |
| **Current thinking** | Where your head is, even half-formed. Say if you want it challenged rather than built |
| **Inspiration** | References, competitors, a screen you like — and the closest existing Flock screen, which matters more than the rest |
| **Already decided** | Anything settled or off limits, so the work stays in scope |
| **How finished it needs to be** | Rough for a critique, or solid enough to hand to engineering |

**If you only send one thing, make it the problem.** If you also know the specific question you want
answered — "toolbar or side panel?" — say so; it keeps the prototype small and pointed at the thing
you actually have to decide.

## How finished

**Say what decision this needs to support**, not a level. "I want to see whether this reads as Flock"
and "engineering needs to build this next sprint" ask for very different amounts of evidence, and
naming the decision gets you the right one without anybody learning a vocabulary.

Whatever you ask for, **you get something that runs and can be clicked.** That part does not scale
down.

## What happens next

The agent writes a brief from what you sent, shows you what it read before it builds anything, then
builds and has the work reviewed for product fit and implementation safety.

**Confirm the brief and correct what it read.** That is the one moment that needs you — a wrong
assumption caught there costs nothing, and the same assumption caught later has already been
polished into the UI. Everything else it writes for you.
